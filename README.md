# ViverSTL

Быстрый и лёгкий просмотрщик STL-файлов для Windows, созданный специально для задач 3D-печати.

## Основные возможности
* **Мгновенный просмотр 3D-моделей** с плавным управлением (вращение ЛКМ, зум колёсиком, перетаскивание `Shift + СКМ`).
* **Листание папки стрелками (`←` / `→`)** — быстрый перебор всех STL-моделей в директории без повторного открытия проводника.
* **Быстрая отбраковка (`Delete`)** — удаление ненужных файлов в Корзину Windows с подтверждением.
* **Симулятор печатной камеры принтера** — встроенные профили Bambu Lab (A1 mini, A1/P1S/P2S/X1C, H2D, H2S) + добавление своих принтеров. Автоматическая проверка габаритов с визуальной тревогой при выходе за рамки стола.
* **Расчёт объёма и веса** — автоматический подсчёт объёма (см³) и примерного веса пластика (PLA / PETG).
* **Ориентация и масштаб** — поворот на 90° по осям X/Y/Z с постановкой на стол и переключение масштаба `мм ↔ дюймы (×25.4)`.
* **Отправка в слайсер в один клик** — прямой запуск выбранного слайсера (Bambu Studio, OrcaSlicer, PrusaSlicer и др.) с текущей моделью.

## Установка и запуск
* **Для пользователей:** скачайте готовый установщик `ViverSTL Setup 1.0.0.exe` во вкладке **[Releases](../../releases)**.
* **Для разработчиков:**
  ```bash
  npm install
  npm start
  ```
